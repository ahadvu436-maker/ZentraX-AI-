# ZentraX Strategic Roadmap Matrix

> **Note on scope:** No document can reliably predict a competitor's actual
> future technical roadmap — that would require nonpublic information
> Claude has no access to. What this file gives you instead is a rigorous
> competitive-positioning framework: plug in your own market research and
> it becomes a working roadmap tool. Treat the example rows as placeholders,
> not forecasts.

## 1. How to use this matrix
1. Fill in **Signal Sources** with what you actually monitor (competitor
   changelogs, job postings, patent filings, conference talks, earnings
   calls).
2. Score each capability area on **Our Maturity** and **Estimated Market
   Maturity** (0–5) using those signals.
3. The **Lead/Lag** column is `Our Maturity − Market Maturity`. Positive =
   ahead, negative = behind.
4. Re-score quarterly. Treat this as a living document, not a one-time
   prediction.

## 3. Signal-gathering checklist
- [ ] Public changelogs / release notes of top 3–5 competitors, reviewed monthly
- [ ] Competitor job postings (role titles reveal investment areas)
- [ ] Patent and standards-body filings
- [ ] Conference talks / engineering blog posts
- [ ] Earnings call transcripts (public companies) for stated R&D priorities
- [ ] Customer/analyst feedback on competitor gaps

## 4. Prioritization framework
Score candidate features on:
- **Strategic differentiation** (1–5): does this create a moat, or just parity?
- **Engineering cost** (1–5, inverse-weighted): lower cost wins ties
- **Time-to-market risk** (1–5): dependency count, unknowns
- **Revenue/retention impact** (1–5): tied to actual customer data, not guesses

`Priority Score = (Differentiation × Revenue Impact) / (Engineering Cost × Time Risk)`
